الخطوة 1 · الشكل النهائي

تجهيز المشروع وCSS الأساسي

صفحة بسيطة فيها عنوان وزرار. شكلها بسيط بس ده الأساس اللي كل الصفحات هتتبني عليه.

هنستخدم:resetbox-sizingflex (body).container.btn

الخطوة 1 · خطوات التنفيذ

خطوات التنفيذ

1
اعمل فولدر اسمه shop وجواه ملفين: index.html وstyle.css.
2
في index.html اكتب هيكل الصفحة، واربط ملف الـ CSS بـ <link> جوه الـ <head>.
3
ضيف <meta name="viewport"> عشان الصفحة تتظبط على الموبايل بعدين.
4
في style.css الغي الـ margin والـ padding الافتراضي بـ * وحط box-sizing: border-box.
5
خلّي الـ body عمود flex بـ min-height: 100vh وmain ياخد flex: 1. كده الـ Footer هينزل تحت حتى لو المحتوى قليل.
6
اعمل .container يحدد عرض المحتوى وينتّصه، و.btn للزراير، وكلاسات العناوين .page-title و.page-sub.

كود الـ HTML

ملف index.html: ده الهيكل اللي هننسخه لكل الصفحات.

index.html
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Lozina Toaster</title> <link rel="stylesheet" href="style.css"> </head> <body> <main class="container section"> <h1 class="page-title">Lozina Toaster</h1> <p class="page-sub">Welcome to our simple online shop.</p> <a href="#" class="btn">Start shopping</a> </main> </body> </html>

الخطوة 1 · الكود

كود الـ CSS

ملف style.css: اكتب الكود ده في أوله.

style.css
/* reset: remove default spacing */ * { margin: 0; padding: 0; box-sizing: border-box; } /* body = flex column, so the footer stays at the bottom */ body { font-family: Arial, sans-serif; background: #f5f7f6; color: #1f2937; min-height: 100vh; display: flex; flex-direction: column; } main { flex: 1; } a { text-decoration: none; color: inherit; } /* centered content wrapper */ .container { width: 90%; max-width: 1100px; margin: 0 auto; } /* spacing and page headings */ .section { padding-top: 50px; } .page-title { font-size: 32px; margin-bottom: 6px; } .page-sub { color: #6b7280; margin-bottom: 28px; } /* main button */ .btn { display: inline-block; background: #7a4b2a; color: #fff; padding: 10px 22px; border: none; border-radius: 6px; font-size: 16px; font-family: inherit; cursor: pointer; } .btn:hover { background: #5e3a20; }

الخطوة 2 · الشكل النهائي

الـ Navbar

لوجو على الشمال، لينكات في النص، وزرارين على اليمين. وهو sticky يعني بيفضل ظاهر فوق وانت بتنزل بالـ scroll.

هنستخدم:display: flexjustify-content: space-betweengapposition: sticky

الخطوة 2 · خطوات التنفيذ

خطوات التنفيذ

1
اكتب <header class="navbar"> وجواه <div class="container nav-inner">. الـ container بيحدد العرض، والـ nav-inner هو الـ flex.
2
حط 3 عناصر جواه: اللوجو <a class="logo">، اللينكات في <nav class="nav-links">، وزراير الحساب في <div class="nav-auth">.
3
خلّي .nav-inner فيه display: flex وjustify-content: space-between وalign-items: center. ده اللي بيوزّع الـ 3 عناصر على الصفحة.
4
خلّي .nav-links و.nav-auth flex هما كمان، مع gap للمسافات بين اللينكات.
5
ثبّت الـ Navbar فوق بـ position: sticky; top: 0 ومعاهم z-index عشان يفضل فوق باقي العناصر.

الخطوة 3 · الشكل النهائي

الـ Footer

3 أعمدة بالـ Grid: عمود كبير عن المتجر وعمودين للينكات، وتحتهم سطر حقوق النشر.

هنستخدم:display: gridgrid-template-columnsfrgap

الخطوة 3 · خطوات التنفيذ

خطوات التنفيذ

1
اكتب <footer class="footer"> في آخر الـ <body>، بعد الـ <main>.
2
جواه <div class="container footer-grid"> وفيه 3 أقسام (div): عن المتجر، الصفحات، الحساب.
3
فعّل الـ Grid بـ grid-template-columns: 2fr 1fr 1fr. يعني العمود الأول ضعف التاني والتالت.
4
حط gap للمسافة بين الأعمدة، وخلّي كل لينك display: block عشان ينزلوا تحت بعض.
5
ضيف سطر الحقوق .copyright تحت الأعمدة، وخط فاصل فوقه بـ border-top.
